准备：两台debian12，都预装docker，一台负责监控，一台负责部署容器

目标：实现基于Prometheus+ grafana监控docker容器的监控系统


--------------------------


### 1、host1:部署lnmp

创建目录
```
mkdir -p ~/lnmp/{nginx,php,mysql,html}
cd ~/lnmp
```

创建docker-compose.yml
```
services:
  nginx:
    image: nginx:alpine
    container_name: nginx
    ports:
      - "80:80"
    volumes:
      - ./html:/var/www/html
      - ./nginx:/etc/nginx/conf.d
    depends_on:
      - php
    restart: unless-stopped

  php:
    image: php:8.3-fpm
    container_name: php
    volumes:
      - ./html:/var/www/html
    restart: unless-stopped

  mysql:
    image: mysql:8.0
    container_name: mysql
    environment:
      MYSQL_ROOT_PASSWORD: rootpass
      MYSQL_DATABASE: webdb
      MYSQL_USER: webuser
      MYSQL_PASSWORD: webpass
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

volumes:
  mysql_data:
```


lnmp配置
```
nano ~/lnmp/nginx/default.conf
```

内容
```
server {
    listen 80;
    server_name _;

    root /var/www/html;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass php:9000;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```


创建phpinfo测试页面
```
echo '<?php phpinfo(); ?>' > ~/lnmp/html/index.php
```

启动
```
cd ~/lnmp
docker compose up -d
```

检查
```
docker ps

curl http://host1
```

### 2、host1部署cadvisor

cadvisor负责采集docker容器的CPU、内存、网络、磁盘的指标。

```
docker run -d \
  --name=cadvisor \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v /:/rootfs:ro \
  -v /var/run:/var/run:ro \
  -v /sys:/sys:ro \
  -v /var/lib/docker:/var/lib/docker:ro \
  gcr.io/cadvisor/cadvisor:latest
```

检查
```
docker ps

curl http://host1:8080/metrics
```

### 3、host2安装Prometheus

```
apt update && apt install -y prometheus
```

修改配置
```
nano /etc/prometheus/prometheus.yml
```

替换为:
```
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: "cadvisor"
    static_configs:
      - targets:
          - "host1:8080"
```


启动prometheus
```
sudo systemctl restart prometheus
sudo systemctl enable prometheus
```


检查

```
systemctl status prometheus
```


浏览器访问host2的9090端口：`Status -> Targets`，应该看到cadvisor显示`state -> UP`

### 4、**host2**安装grafana

```
apt install -y apt-transport-https software-properties-common wget
```

添加grafana仓库
```
mkdir -p /etc/apt/keyrings

wget -q -O - https://apt.grafana.com/gpg.key | \ gpg --dearmor -o /etc/apt/keyrings/grafana.gpg

echo "deb [signed-by=/etc/apt/keyrings/grafana.gpg] https://apt.grafana.com stable main" | \
   tee /etc/apt/sources.list.d/grafana.list
```


安装
```
 apt update && apt install -y grafana
```

启动grafana
```
systemctl enable --now grafana-server

# 检查
systemctl status grafana-server
```



### 5、Grafana添加Prometheus

访问http://host2:3000

进入grafana，按以下步骤操作：
```
Connections
→ Data sources
→ Add new data source
→ Prometheus
```

url填写  `http://localhost:9090`

点击   `save & test`

![](/assets/img/Pasted image 20260904135416.png)

配置成功即可



-----------------

### 6、grafana创建docker监控仪表盘

进入：
```
Dashboards
→ New
→ Import
```

输入一个cadvisor的仪表盘 ID，这里我输入的是 `14282`

选择刚刚添加的Prometheus

点击 `import`

导入仪表盘以后

点击dashboard->cadvisor exporter

进入容器的监控面板，可以监控容器的cpu、内存、磁盘、网络状况
