
**架构**

host1在原有基础上，新增node exporter和cadvisor

host2新增altermanager


**所有组件**

Node Exporter → 看服务器
cAdvisor      → 看容器
Prometheus    → 存指标 + 判断异常
Promtail      → 收集日志
Loki          → 存日志 + 查日志
Alertmanager  → 发告警
Grafana       → 统一展示


### 1、host1增加node exporter

node exporter 用来监控host1本身，不修改lnmp


运行node exporter容器
```
docker run -d \
  --name node-exporter \
  --restart unless-stopped \
  --network host \
  --pid host \
  prom/node-exporter:latest
```

访问 `curl http://127.0.0.1:9100/metrics`

能看到指标信息就行

### 2、host2配置Prometheus

```
nano /etc/prometheus/prometheus.yml
```

添加内容如下
```
scrape_configs:

  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']

  - job_name: 'node'
    static_configs:
      - targets: ['host1:9100']

  - job_name: 'cadvisor'
    static_configs:
      - targets: ['host1:8080']
```


检查配置是否有问题
```
promtool check config /etc/prometheus/prometheus.yml
```

没有问题重启Prometheus
```
systemctl restart prometheus
```

```

systemnctl restart prometheus
```



### 6、设置告警规则

host2

```
mkdir -p /etc/prometheus/rules

# 创建规则
nano /etc/prometheus/rules/node.yml
```

写入：
```
groups:
  - name: node-alerts
    rules:

      - alert: TargetDown 
        expr: up == 0 
        for: 1m 
        labels: 
          severity: critical 
        annotations: 
          summary: "Monitoring target is DOWN" 
          description: "{{ $labels.instance }} is no longer being scraped for metrics"
```

在 `/etc/prometheus/prometheus.yml` 增加：
```
rule_files:
  - "/etc/prometheus/rules/*.yml"
```

检查配置
```
promtool check rules /etc/prometheus/rules/node.yml
```

重启
```
systemctl restart prometheus
```


host1执行
```
docker stop node-exporter
```

### 7、host2部署loki

```
 mkdir -p /opt/loki
 nano /opt/loki/loki-config.yml
```

写入：
```
auth_enabled: false

server:
  http_listen_port: 3100

common:
  path_prefix: /loki
  replication_factor: 1
  ring:
    kvstore:
      store: inmemory

schema_config:
  configs:
    - from: 2024-01-01
      store: tsdb
      object_store: filesystem
      schema: v13
      index:
        prefix: index_
        period: 24h

storage_config:
  filesystem:
    directory: /loki/chunks

limits_config:
  allow_structured_metadata: false
  volume_enabled: true
```


启动：
```
docker run -d \
  --name loki \
  --restart unless-stopped \
  -p 3100:3100 \
  -v /opt/loki:/etc/loki \
  -v loki-data:/loki \
  grafana/loki:latest \
  -config.file=/etc/loki/loki-config.yml
```

等待一会执行：
```
curl http://127.0.0.1:3100/ready
```

返回 `ready` 即可

### 8、host1部署promtail

```
mkdir -p /opt/promtail
nano /opt/promtail/promtail-config.yml
```


写入：
```
server:
  http_listen_port: 9080

positions:
  filename: /tmp/positions.yaml

clients:
  - url: http://host2:3100/loki/api/v1/push

scrape_configs:
  - job_name: docker
    static_configs:
      - targets:
          - localhost
        labels:
          job: docker
          host: host1
          __path__: /var/lib/docker/containers/*/*-json.log
```

在path配置使用了通配符 `*` ，匹配host1上所有容器的json日志




启动promtail
```
docker run -d \
  --name promtail \
  --restart unless-stopped \
  -v /opt/promtail:/etc/promtail \
  -v /var/lib/docker/containers:/var/lib/docker/containers:ro \
  grafana/promtail:latest \
  -config.file=/etc/promtail/promtail-config.yml
```

docker ps
